# Rekha's world: every prompt, in order

Her world is the village: home workshop → lane and bank → courtyard → lane → her new shop.
Every prompt is complete. Copy one block, paste it, attach what it says, then generate.

**What "your panorama" means:** the one long line-art picture of Rekha's village you already made (8614 × 2367). Attach it whenever a step says to.

**Rules for every background layer:**
- Keep the output the same shape as the panorama (about 3.6 : 1). If the tool changes it, scale the result back to 8614 × 2367 in Figma.
- Generate on white, vectorise, then delete the white.
